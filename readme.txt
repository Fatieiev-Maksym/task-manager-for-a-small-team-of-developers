A web-based task management system designed for small software development teams.

Technology stack:
- Backend (Python, framework Django)
- Frontend (HTML, CSS)
- Database (PostgreSQL)

Features:
- Team and project management
- Task creation and status management
- Task priorities
- Role-based access control
- Comments and file attachments
- Team and private communication
- Notifications
- Deadline notifications
- Dashboard for monitoring projects and tasks

User roles:
- Team Lead (manages the team, projects, tasks and users)
- Developer (works with assigned tasks)
- Tester (works with assigned tasks and testing)
- Viewer (has read-only access to the avaible project information)
